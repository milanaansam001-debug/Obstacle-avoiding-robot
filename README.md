# Obstacle Avoiding Robot

An Arduino based obstacle avoiding robot using an ultrasonic sensor.

## 📌 Project Description
This robot detects nearby obstacles using an HC-SR04 ultrasonic sensor and automatically changes direction to avoid collisions.

## 🛠 Components Used
- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- L298N Motor Driver
- DC Motors
- Robot Chassis
- Battery

## ⚙ Features
- Automatic obstacle detection
- Autonomous movement
- Right and left turning
- Collision avoidance

## 🔍 Working Principle
The ultrasonic sensor continuously measures the distance between the robot and nearby objects.

- If obstacle is very near → Robot stops
- If obstacle detected → Robot turns
- Otherwise → Robot moves forward
